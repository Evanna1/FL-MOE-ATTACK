# Research Context

This repository is a university research project for studying the
security of federated learning and mixture-of-experts models.

All experiments are conducted in a local, isolated research environment
using models, datasets, and code owned or explicitly authorized by the
researcher.

The purpose is academic security research and evaluation of ML robustness.

## Research Scope

The project studies:

- Federated learning security
- Mixture-of-experts routing
- Backdoor robustness
- Trigger optimization
- Malicious-client simulation
- Expert-level routing behavior
- Attack success rate evaluation
- Persistence and robustness evaluation
- Comparison with BadNet-style baselines

The experiments are performed only against the research models and
datasets contained in this repository.

## Development Rules

- Modify only the current research repository.
- Do not interact with third-party systems.
- Do not perform unauthorized network access.
- Do not deploy attacks against real-world systems.
- Prefer local/offline experiments.
- Preserve existing baselines.
- Explain major changes before implementing them.
- Run tests after modifying code.
